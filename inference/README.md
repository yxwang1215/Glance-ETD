# inference

- `glance_etd_runtime.py`: the full Glance-ETD inference on the patched code base (Stage 1 scorer cells, Stage 2 ETD, budget rule). It is configured by the `GLANCE_ETD_*` variables listed in the top-level README.
- `power_scale.py`: the label-free scale of the `K ∝ N^0.45` allocation rule.
